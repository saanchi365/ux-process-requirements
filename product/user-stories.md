# User stories

What our users want from the contract management tool as a whole, written as: **As a** (who) **I want to** (what) **so that I can** (why). Grouped by the users described in [user understanding](user-understanding.md).

## Business user

- As a **business user**, I want to **start a contract without knowing legal terms**, so that I can **get deals moving without waiting on legal**.
- As a **business user**, I want to **see where my contract is at any time**, so that I can **stop chasing people for updates**.
- As a **business user**, I want to **find all my contracts in one place**, so that I can **avoid digging through emails and folders**.
- As a **business user**, I want to **be told when something needs my action**, so that I can **respond on time without checking the tool all day**.

## Legal team

- As a **legal team member**, I want to **have every contract the company has ever signed in one place**, so that I can **answer any question about a contract quickly**.
- As a **legal team member**, I want to **make sure contracts use our approved wording**, so that I can **reduce risk without reviewing every line myself**.
- As a **legal team member**, I want to **see every version of a contract and what changed**, so that I can **understand how a contract was agreed**.
- As a **legal team member**, I want to **spend less time on routine contracts**, so that I can **focus on the ones that need real legal attention**.

## Approver

- As an **approver**, I want to **see only what I need to decide**, so that I can **approve or reject quickly, even on my phone**.
- As an **approver**, I want to **know what changed since I last looked**, so that I can **avoid reading the whole contract again**.
- As an **approver**, I want to **explain my decision in a few words**, so that I can **make sure the owner knows exactly what to fix**.

## Admin

- As an **admin**, I want to **set up the tool to match how our company is organised**, so that I can **make sure contracts follow the right rules for each part of the business**.
- As an **admin**, I want to **change settings without breaking work in progress**, so that I can **keep the tool up to date with confidence**.
- As an **admin**, I want to **bring in our existing contracts and data on day one**, so that I can **have people use the tool from the start instead of keeping old spreadsheets**.
