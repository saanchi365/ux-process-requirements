# Drafts

Wireframes you've drawn but haven't placed yet. Any name is fine here, e.g. `upload-screen-idea.excalidraw.svg`.

When you know which requirement it belongs to:
1. Drag it into that requirement's `wireframes/images` folder, e.g. `requirements/R016-contract-version-history/wireframes/images/`.
2. Rename it by the rule, e.g. `R012-W03-version-details.excalidraw.svg`.
3. Commit. Its page is made automatically.
